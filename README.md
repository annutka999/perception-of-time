# Всё быстрее — интерактивное эссе о времени

Обычный статичный сайт: **откройте `index.html` двойным кликом** в браузере. Ничего устанавливать не нужно. Для шрифтов нужен интернет (Google Fonts; без него подставятся запасные).

## Подобрать оттенок синего
Откройте `index.html#dev`: внизу появится панель с четырьмя оттенками. Когда выберете, впишите три значения в начало `src/stylesheets/style.css` (`--blue`, `--blue-hi`, `--blue-lt`), затем удалите файл `src/javascripts/shade.js` и его строку `<script>` внизу `index.html`.

## Идея дизайна
Бумага — всё записанное часами и объяснённое. Синий — всё, что часами не измеряется: переживание и память. Три шрифта = три времени: Martian Mono (часы), Roboto Flex (переживание), Literata (память). Подробности и правила — на странице «Дизайн-система v1».

## Графика
Все изображения (кадры дня в зоне 4, эпизоды в зоне 6, «негатив читателя» в финале) рисуются кодом в `src/javascripts/art.js` и подписаны как нарисованные. Фотографий на странице нет. Если появятся настоящие фото, положите их в `src/images/` и подпишите источник.

## Структура
```
index.html                  разметка 9 зон + подвал (тексты правятся здесь)
src/
├── fonts/  images/         свои шрифты и фото
├── javascripts/
│   ├── data.js             ВСЕ ДАННЫЕ: события дня, реплики ночи, даты автора, моменты
│   ├── session.js          общий цикл и активное время читателя
│   ├── art.js              фотограммы и кадры (графика нарисована кодом, цвета из CSS)
│   ├── graphics.js         палитра из CSS, циферблат и маятник бессонной ночи
│   ├── sections.js         сборка зон из данных
│   ├── scroll.js           появление и «забывание», проявка в зоне 4, поверхности, шапка
│   ├── experiment.js       зона 5: «десять секунд» (две попытки)
│   ├── finale.js           зона 9: вопрос, время автора, память читателя, протокол
│   ├── cursor.js           курсор
│   ├── nav.js              содержание (кнопка «зона» вверху справа) и «пройти заново»
│   └── shade.js            служебная панель (#dev): подбор оттенка и проверка загрузки
└── stylesheets/
    ├── reset.css, fonts.css, style.css, layout.css, adaptive.css, animation.css
```
CSS подключается в `index.html` в порядке: reset → fonts → style → layout → adaptive → animation.

## Что заполнить
- `src/javascripts/data.js`, блок `T.AUTHOR`: реальные даты черновиков `'ГГГГ-ММ-ДД'` вместо `null`. Пока там `null`, видны поля «[дата — заполнить]».
- В подвале (`index.html`): описание участия ИИ (поле в квадратных скобках).

## Как измеряется время читателя
Отсчёт начинается при загрузке страницы, останавливается, пока вкладка скрыта, продолжается при возвращении и замирает в момент ответа на вопрос в зоне 9. Это активное время на странице, а не точная мера внимания.

## Если на GitHub выглядит иначе, чем на компьютере
1. Откройте опубликованную страницу с `#dev` в конце адреса (например `https://логин.github.io/vse-bystree/#dev`). Вверху слева появится проверка: какие модули загрузились (✓ или ✗), нашлись ли цвета в CSS и какие были ошибки. Сделайте скриншот, если что-то не так.
2. Проверьте на github.com, что в репозитории есть `index.html` в корне и папка `src` целиком: в `src/javascripts` 10–11 файлов, в `src/stylesheets` 6 файлов. Имена файлов в GitHub Pages чувствительны к регистру: всё должно быть строчными буквами, как в проекте.
3. После каждого пуша подождите минуту и обновите страницу жёстко (Cmd+Shift+R) или откройте её в приватном окне: браузер любит держать старые CSS и JS.
4. Чтобы браузер точно взял свежие файлы, меняйте число в `?v=9` на следующее во всех ссылках `index.html` (поиск и замена `?v=9` на `?v=10`).
5. Если в GitHub Desktop слева остались «изменённые файлы», значит, не всё закоммичено: нажмите Commit to main, затем Push origin.

## Публикация на GitHub Pages
Все файлы в репозиторий так, чтобы `index.html` лежал в корне. Settings → Pages → ветка `main`, папка `/ (root)`.
