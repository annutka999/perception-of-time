# «Всё быстрее»: интерактивное эссе о времени

Открывается двойным щелчком по `index.html`, сборка не нужна.

## Структура
```
index.html                  разметка девяти зон и подвала
NOTES.md                    решения, система шрифтов, проверки
src/
├── fonts/                  (пусто) свои шрифты
├── images/                 (пусто) изображений в работе нет
├── javascripts/
│   ├── data.js             ВСЕ ДАННЫЕ: события дня, реплики ночи, дни зоны 6, даты автора, соседние работы
│   ├── typo.js             неразрывные пробелы: короткие слова не висят в конце строки
│   ├── session.js          общий цикл и счётчик активного времени
│   ├── graphics.js         палитра из CSS и циферблат ночи
│   ├── sections.js         сборка зон из данных
│   ├── scroll.js           главное свойство: прокрутка как время; состояния зоны 4; забывание после поворота
│   ├── experiment.js       зона 5: опыт «десять секунд»
│   ├── finale.js           зона 9: оценка читателя, часы, три времени, вывод
│   └── shade.js            служебная панель: index.html#dev
└── stylesheets/
    ├── reset.css
    ├── fonts.css           переменные: шрифт Geist, шесть размеров, шаг ритма, цвета
    ├── style.css           шесть текстовых стилей и компоненты
    ├── layout.css          зоны, закрепление, режим без закрепления
    ├── adaptive.css        телефон
    └── animation.css       единственное движение: «забывание»
```

## Публикация на GitHub Pages
1. Распакуйте архив так, чтобы `index.html` лежал в корне репозитория.
2. GitHub Desktop: Commit, затем Push origin.
3. Settings → Pages → Branch: main, folder: / (root).
4. После правок меняйте число в `?v=37` на следующее во всех ссылках `index.html`, чтобы браузер взял свежие файлы.

## Если на GitHub выглядит иначе
1. Откройте страницу с `#dev` в конце адреса: вверху слева видно, какие модули загрузились и какие были ошибки.
2. Проверьте, что в `src/javascripts` десять файлов плюс `shade.js`, в `src/stylesheets` шесть. Имена файлов чувствительны к регистру.
3. Обновите страницу жёстко (Cmd+Shift+R).
