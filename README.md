# Всё быстрее — интерактивное эссе о времени

Обычный статичный сайт: **откройте `index.html` двойным кликом** в браузере. Ничего устанавливать и собирать не нужно. (Нужен интернет для шрифтов Google; без него подставятся обычные шрифты.)

## Структура
```
index.html                  разметка 9 зон (тексты правятся здесь)
src/
├── fonts/                  свои шрифты (если нужны)
├── images/                 свои фото (если нужны)
├── javascripts/
│   ├── data.js             ВСЕ ДАННЫЕ: события дня, реплики ночи, даты автора, моменты
│   ├── session.js          общий цикл и активное время читателя
│   ├── graphics.js         заставка, циферблат и маятник ночи, полутоновые «фото»
│   ├── sections.js         сборка зон из данных
│   ├── scroll.js           появление и «забывание», прорисовка, зоны, шапка
│   ├── experiment.js       зона 5: «десять секунд» (две попытки)
│   ├── finale.js           зона 9: вопрос, время автора, память читателя, протокол
│   └── cursor.js           курсор
└── stylesheets/
    ├── reset.css           сброс стилей
    ├── fonts.css           шрифты и переменные --g --s --m
    ├── style.css           цвета, типографика, компоненты
    ├── layout.css          раскладка зон и сеток
    ├── adaptive.css        мобильная композиция (до 900px и 700px)
    └── animation.css       анимации, переходы, курсор, зерно
```
Файлы подключаются в `index.html` в таком порядке: reset → fonts → style → layout → adaptive → animation; скрипты — в порядке, указанном внизу страницы (он важен).

## Что заполнить обязательно
В `src/javascripts/data.js`, блок `T.AUTHOR`: замените `null` на реальные даты `'ГГГГ-ММ-ДД'` ваших черновиков. Пока там `null`, на странице стоят поля «[дата — заполнить]». Срок создания считается автоматически из первой и последней даты. Ничего не придумывается.

## Как измеряется время читателя
Отсчёт начинается при загрузке страницы, останавливается, пока вкладка скрыта, продолжается при возвращении и замирает в момент ответа на вопрос в зоне 9. Это активное время на странице, а не точная мера внимания.

## Публикация на GitHub Pages
Загрузите все файлы в репозиторий так, чтобы `index.html` лежал в корне. Settings → Pages → ветка `main`, папка `/ (root)`.
